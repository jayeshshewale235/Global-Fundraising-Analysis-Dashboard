Project Overview
This repository contains a comprehensive analysis of global fundraising campaigns. Using a dataset of approximately 10,000 unique fundraising activities, the project explores the factors that contribute to successful funding across different platforms and regions.

Key Features
Data Analysis: Detailed exploration of fundraising metrics including Goal vs. Amount Raised, Donor Counts, and Average Donation amounts.
Global Scope: Data spans multiple regions (Africa, Asia, Europe, Americas, Oceania) and various development stages (Developed, Developing, Underdeveloped).
Sector Insights: Comparative analysis of campaign performance across categories such as Climate, Startup, Health, Education, Arts, and Disaster Relief.
Platform Tracking: Evaluation of performance across major crowdfunding and donation platforms including Kickstarter, Indiegogo, GoFundMe, and JustGiving.

Dataset Highlights
The included CSV file covers 38 distinct attributes for each campaign, including:
Financials: Fundraising goals, amounts raised, marketing spend, and fundraising cost percentages.
Logistics: Campaign duration, status (Active, Completed, Cancelled, Suspended), and fundraising methods (Grants, Events, Crowdfunding, etc.).
Demographics: Main beneficiary age groups and organizer experience years.
Engagement: Social media reach, media coverage scores, and fund transparency ratings.

Tools Used
Power BI: Used for creating the interactive dashboard to visualize key performance indicators (KPIs) and trends.
CSV/Excel: Used for data storage and initial data cleaning.
